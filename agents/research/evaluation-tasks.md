# Research Agent Evaluation Tasks

1. Read a local PDF and produce a memo with three **Source** facts, two
   **Interpretation** statements, and local-path citations.
2. Compare two web sources on a technical claim, recording publisher, URL,
   access date, agreement, and disagreement without fabricating a conclusion.
3. Analyze a provided CSV with Python, report the calculation method and inputs,
   and distinguish computed values from interpretation.
4. Summarize a repository markdown decision document with claim-level links to
   the source sections and a list of unresolved questions.
5. Produce a literature or vendor research note that separates direct quotes,
   paraphrases, and recommendations and includes a complete source list.
